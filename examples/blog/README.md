# Blog Example Preset

This is an installable Twill preset that provides a complete blog structure with posts, categories, and authors.

## Features

- **Posts Module**: Blog posts with title, excerpt, content, featured images, and publication dates
- **Categories Module**: Organize posts into categories
- **Authors Module**: Manage post authors with bio and avatar
- **Relationships**: Posts can be linked to authors and multiple categories
- **Block Editor**: Rich content editing with Twill's block editor
- **Translatable Content**: All content fields support multiple languages
- **Revisions & Slugs**: Full revision history and SEO-friendly slugs

## Modules

### Posts
- Translatable title, excerpt, and description
- Author browser field (single select)
- Multi-select categories
- Publish date picker
- Cover image media field
- Block editor for rich content

### Categories
- Translatable title and description
- Cover image
- Linked to posts

### Authors
- Translatable name and bio
- Avatar image
- Linked to posts

## Installation

This preset can be installed as a starting point for a blog-based Twill application. All modules are configured with proper navigation, routes, and database migrations.
