# Multilingual Example Preset

This is an installable Twill preset that demonstrates multilingual content management with a simple page-based structure.

## Features

- **Pages Module**: Manage multilingual pages with translated content
- **Multiple Languages**: Pre-configured with English, French, Spanish, and German
- **Translatable Content**: All content fields support translation across all configured locales
- **Page Reordering**: Sortable pages with position management
- **Block Editor**: Rich content editing with Twill's block editor
- **Revisions & Slugs**: Full revision history and locale-specific slugs

## Modules

### Pages
- Translatable title, description, and content
- Cover image media field
- Block editor for rich content
- Position-based ordering (drag and drop reordering)

## Languages

The preset comes with four pre-configured languages:
- English (en) - Default
- French (fr)
- Spanish (es)
- German (de)

## Installation

This preset can be installed as a starting point for a multilingual website or application. All content can be managed across multiple languages from the Twill admin interface.

## Locale Configuration

The locale configuration in `config/twill.php` can be customized to add or remove languages as needed. Each locale includes:
- Label: Display name in the admin
- Published: Whether the locale is active
